# TASTIE tomato — root architecture ± Trichoderma (mirror)

Curated imaging + RSML from the [TASTIE_tomato](https://github.com/dr-richard-barker/TASTIE_tomato)
study (tomato, *Solanum lycopersicum*, roots ± *Trichoderma* fungi; APEX10/SVT
proposal) for the AstroBotany calibration image database. (RNA-seq / supplementary
tables in the source repo are not included.)

- `images/` — 48 web-compressed root/plant images (control vs +Trichoderma) + `metadata.csv`.
- `rsml_index.json` — 49 SmartRoot RSML traces (served from the TASTIE repo),
  grouped by treatment × plant, for the AstroRoot dashboard. RSML basenames match
  the image basenames, so traces and photos correspond.

Source: dr-richard-barker/TASTIE_tomato.
