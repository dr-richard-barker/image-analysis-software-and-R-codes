# TICTOC — cotton spaceflight root architecture (mirror)

Curated imaging, timelapse and RSML from the [TICTOC](https://github.com/dr-richard-barker/TICTOC)
cotton (*Gossypium*) spaceflight study — flight (ISS) vs ground control, days 3–6 —
for the AstroBotany calibration image database.

- `images/` — 64 web-compressed cotton root crops (TIFF originals are 6–9 MB each,
  300 dpi; not mirrored) + `metadata.csv` (condition, day, sample) + a
  timelapse MP4 (transcoded from the study's AVI).
- `rsml_index.json` — 198 SmartRoot RSML traces (served from the TICTOC repo),
  grouped by condition × day, for the AstroRoot dashboard.

Source: dr-richard-barker/TICTOC.
